The aep site does not call withProductSite: it loads only the shared tokens and its own custom.css, which sets prose
link underlines to a low-contrast colour (`--ep-underline`), lets `code` and tables run past a 390 px viewport
and leaves scrolling tables unfocusable. These are aep's own styles (repository aep, website/src/css/custom.css),
so the fix belongs to the aep site; moving aep to withProductSite would be a design decision for its owners.
