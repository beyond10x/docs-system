# UXF-013: A documentation card cuts its title and description with an ellipsis

- id: UXF-013
- title: A documentation card cuts its title and description with an ellipsis
- class: layout
- severity: S3
- metric: layout.truncated
- status: closed
- found_by: R-02 trial: ess and connectors category pages seen in shots
- evidence_recording: none (no recordings in R-02)
- evidence_screenshot: ux/rounds/R-02/shots/sites/ess/worst-1.png
- evidence_lines: ux/rounds/R-02/shots/sites/ess/worst-1.png: /docs/guides cards read "Generate contracts and do...", "Bind commands and views..."
- regression_asset: tests/ux-r02.test.mjs UXF-013

Generated category pages (Docusaurus DocCardList) put Infima's `text--truncate` on each card's title and
description: one line, cut with an ellipsis. The full text is only in the `title` attribute, which a
touch reader and a keyboard reader never see, and the cut descriptions lose the one sentence that says
what the page is. The gate's truncation check accepts it because the attribute holds the full value.
Seen on every category page of ess and connectors.

Severity S3: the pages stay usable, the cost is an extra click to learn what a card is.

Fix: `.card .text--truncate` wraps (`white-space: normal`, no clipping). Red on the R-01 CSS (no such rule), green after.
