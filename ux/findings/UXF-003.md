# UXF-003: a link in documentation prose looks like its text

- severity: S1
- metric: axe.serious_critical (link-in-text-block)
- status: open, in R-01's change set
- found_by: R-01 round command, axe-core
- evidence_recording: none (no recordings in R-01)

A link inside a paragraph has no underline, and its colour differs from the body text by 1.03:1
(link #17684a on text #4f625d in light), so the reader cannot see that "heroes page" on /docs/art
is a link. Every product site inherits this for every inline link in its documentation.

Severity S1: it fails hard gate 5 at both gating viewports, so no merge can pass with it.

Fix: links inside documentation paragraphs, list items, table cells and quotes are underlined.
