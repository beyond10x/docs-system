# UXF-002: session chart marks carry an aria-label their element may not have

- id: UXF-002
- title: Session chart marks carry an aria-label their element may not have
- class: affordance
- severity: S1
- metric: axe.serious_critical (aria-prohibited-attr)
- status: open, in R-01's change set
- found_by: R-01 round command, axe-core
- evidence_recording: none (no recordings in R-01)
- evidence_screenshot: ux/rounds/R-01/shots/pages (session page, every viewport)
- evidence_lines: ux/rounds/R-01/report.md, "Failing checks", /session
- regression_asset: tests/product-site.browser.mjs check UXF-002

The session charts render each bar and marker as a focusable `<g class="b10x-chart-mark"
aria-label="…">` with no role. `aria-label` is prohibited on a `g` without a role, so screen
readers may drop the label and announce nothing when the mark takes focus: 109 marks on /session.

Severity S1: it fails hard gate 5 at both gating viewports, so no merge can pass with it.

Fix: each mark takes `role="img"`, which allows the label and keeps the mark focusable.
