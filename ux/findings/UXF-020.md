# UXF-020: on a phone, two lines of breadcrumb and the "On this page" bar push the page title down

- title: On a phone, a wrapped breadcrumb and the "On this page" bar push the page title to 28 percent of the screen
- class: layout
- severity: S3
- metric: new, docs.h1_top_390 (y of the page H1 on a docs page at 390x844)
- status: open
- found_by: R-02 heuristic reviewer, heuristic 8
- evidence_recording: none (no recordings in R-02)
- evidence_screenshot: ux/rounds/R-02/shots/sites/ess/page-docs-390x844-light.png, ux/rounds/R-02/shots/sites/llm/contact-sheet-light.png (390x844 docs frame)

- regression_asset: none

On every docs page at 390x844 the reader passes the navbar, a breadcrumb that wraps to two lines when
the page title is long, and a full-width collapsed table of contents before the H1. Seen on ess,
llm, connectors, inference and spindle; all share the Docusaurus mobile layout. The first screen
holds one line of the page's own text more than 600 px lower than it could.

Sessions: all docs pages at 390x844 (one frame per site; 768x1024 shows the same stack in a smaller share). Cost: S.

Fix: keep the breadcrumb to one line (hide the page's own title in it) and let the table of contents sit below the lead paragraph.
