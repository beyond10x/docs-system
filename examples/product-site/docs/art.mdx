# Hero art from spec data

`product.art` in `product.json` picks one of five kinds. Each reads a generated file; none is
drawn by hand. The [heroes page](/heroes) shows each kind at landing width with its KPI row.

| Kind | Reads | Typical product |
| --- | --- | --- |
| `terminal` | `b10x-terminal/1` | a command-line tool with a recorded session |
| `protocol-graph` | `b10x-protocol-graph/1` | a protocol language |
| `domain-graph` | `b10x-domain-graph/1` | an ESS-specified product |
| `case` | `b10x-case/1` | a case evaluated more than once |
| `code-pair` | `b10x-code-pair/1` | a generator: source in, contract out |

## Case card

Two `canon evaluate` runs over the same evidence. Only the case moved, from r1 to r2. Claims are
truth chips; outcome states are neutral words, because they are not truth values.
