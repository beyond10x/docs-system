## A protocol with case inputs

One protocol can describe several kinds of change. The case input is listed under the graph, an
`input` predicate leaf tests it, and an obligation shows when it applies before what discharges it.

<ProtocolGraph data={softwareChangeProfiled} caption="One protocol, three kinds of change." />

## A protocol that depends on the order of evidence

Canon's order forms test the order of evidence: a `first` leaf tests the result of the first evidence of
a kind, a `before` leaf that one kind of evidence precedes another, either about a named subject.

## A table wider than the column

| Leaf | Shape in `canon-ir/1` | Example | Reads as |
| --- | --- | --- | --- |
| `evidence` | `{"evidence": {"kind": <kind>, "result": <result>}}` | `{"evidence": {"kind": "tests.passed", "result": "pass"}}` | `evidence = pass: tests.passed` |
| `first` | `{"first": {"kind": <kind>, "result": <result>}}` | `{"first": {"kind": "review.approved", "result": "pass"}}` | `first evidence = pass: review.approved` |
| `before` | `{"before": {"first": <kind>, "then": <kind>}}` | `{"before": {"first": "regression.test", "then": "fix.merged"}}` | `evidence regression.test before fix.merged` |
| `after` | `{"after": {"first": <kind>, "then": {"kind": <kind>, "result": <result>}}}` | `{"after": {"first": "tests.written", "then": {"kind": "tests.run", "result": "fail"}}}` | `evidence = fail: tests.run after tests.written` |
| `input` | `{"input": {"id": <id>, "in": [<value>, …]}}` | `{"input": {"id": "change.size", "in": ["large"]}}` | `input change.size in large` |
