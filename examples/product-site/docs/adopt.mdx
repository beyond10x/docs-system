## One config line

```ts title="website/docusaurus.config.ts"
import {withProductSite} from '@beyond10x/docs-system/product-site';

export default withProductSite(config, {landing: './product.json', mark: 'C'});
```

`withProductSite` adds the product plugin (tokens, theme layer, MDX components, landing route), the
matched Prism themes, and a dark default that still follows the reader's system preference.

## The landing page is data

`product.json` is a `b10x-product-landing/1` document: the promise, the actions, and an ordered list
of sections. A section that names a file (`"data": "data/protocol.json"`) is read and checked at build
time. The landing page takes the route `/`, so documentation moves to `routeBasePath: 'docs'`.

## Generated inputs

| Input | Format | Emitted by |
| --- | --- | --- |
| Hero and terminal sessions | `b10x-terminal/1` | the repository's generator, from a real run |
| Protocol graph | `b10x-protocol-graph/1` | from `canon compile` output |
| Domain graph | `b10x-domain-graph/1` | from `ess specify compile` output |

JSON Schemas for each are exported from `@beyond10x/docs-system/schema/*`.
