The product-site layer adds these components to every MDX page; no import is needed. Each one below
is rendered from a real input: a recorded command session, the Canon status as of 2026-10-04, and the
sibling product sites.

## Terminal

A recorded `b10x-terminal/1` session, generated by running the commands. The copy button copies the
commands only, never the output.

<Terminal session={canonSession} />

The same component takes a verbatim transcript as children. `$ ` starts a command and `# ` a comment
before it. With `animate`, the commands type out once; reduced motion turns that off.

<Terminal title="canon / repository root" animate caption="Quoted from a run at canon 323038d.">{`
# The compiled form names its format.
$ canon compile --path fixtures/investigation/protocol.yaml | jq -r .format
canon-ir/1
`}</Terminal>
